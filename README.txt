ATITHI DIGITAL MENU - ITEM BASED VERSION

This version does NOT display the menu as an image.
All visible dishes and prices are HTML/JavaScript data.

Features:
- Mobile-first responsive design
- Search dishes by name
- Category navigation
- Item-by-item prices
- Free GitHub Pages compatible
- No database or paid service required

To publish:
1. Create a public GitHub repository, e.g. atithi-menu.
2. Upload index.html and menu-data.json.
3. Settings -> Pages -> Deploy from branch -> main -> /(root).
4. Open the GitHub Pages URL.
5. Later, point a static QR code to that URL.

Important:
The menu was transcribed from the uploaded menu images. Please verify spelling/prices before printing the final QR code.
